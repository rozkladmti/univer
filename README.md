# 🎓 Система розкладу навчального закладу

Інтелектуальна екосистема управління навчальним процесом університету.

🌐 **Демо:** [rozkladmti.github.io/univer](https://rozkladmti.github.io/univer/)

---

## 📋 Модулі системи

| Модуль | Опис |
|--------|------|
| 👨‍💼 **Адмін-панель** | Повнофункціональна панель диспетчера розкладу. Drag & Drop, контроль конфліктів, обробка запитів |
| 🏛️ **Панель декана** | Зведений огляд розкладу факультету по кафедрах. Фільтри, експорт в Excel/PNG |
| 🏫 **Панель кафедри** | Управління розкладом кафедри. Обробка запитів від викладачів, розширені фільтри, експорт в Excel та PNG. |
| 👨‍🏫 **Додаток викладача** | Персональний розклад, подача запитів на перенесення, мульти-вибір варіантів |
| 👨‍🎓 **Додаток студента** | Мобільний перегляд розкладу по групах, статус пар в реальному часі |

## ✨ Ключові можливості

- Інтуїтивний Drag & Drop редактор розкладу
- Автоматична перевірка конфліктів (аудиторії, викладачі, групи)
- Система запитів на зміни з мульти-вибором варіантів
- Ієрархія доступу: адмін → декан → кафедра → викладач → студент
- Підтримка парних/непарних тижнів
- Повна історія змін та версіонування
- Адаптивний дизайн (комп'ютер / планшет / телефон)
- Темна тема з автозбереженням
- Експорт даних (Excel, PNG)
- Хмарна синхронізація через Google Sheets

## 🛠️ Технологічний стек

- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** Google Apps Script
- **Database:** Google Sheets
- **Infrastructure:** Serverless (Google Workspace), GitHub Pages
