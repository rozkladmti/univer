🎓 Система розкладу навчального закладу

Інтелектуальна екосистема управління навчальним процесом

👨‍💼 Адмін-панель

Повнофункціональна панель для диспетчера розкладу. Створення, редагування, перенесення пар. Робота з запитами від кафедр та викладачів.

Демонстрація

🏛️ Для декана

Зведений огляд розкладу факультету. Перегляд по кафедрах, розширені фільтри, експорт в Excel та PNG.

Демонстрація

🏫 Для кафедри

Повне управління розкладом кафедри. Обробка запитів від викладачів, розширені фільтри, експорт в Excel та PNG.

Демонстрація

👨‍🎓 Для студентів

Мобільний інтерфейс для перегляду розкладу. Фільтрація по групах, офлайн режим, сповіщення про зміни.

Демонстрація

👨‍🏫 Для викладачів

Персональний розклад, швидка подача запитів на перенесення занять, комунікація з диспетчером.

Демонстрація

🎯 Ключові можливості

  • Інтуїтивний Drag & Drop редактор розкладу
  • Автоматична перевірка конфліктів (аудиторії, викладачі, групи)
  • Система запитів на зміни з мульти-вибором варіантів
  • Ієрархія доступу: адмін → декан → кафедра → викладач → студент
  • Підтримка парних/непарних тижнів
  • Повна історія змін та версіонування
  • Адаптивний дизайн (Комп'ютер / Планшет / Телефон)
  • Експорт даних (PDF, Excel, зображення)
